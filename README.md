Entry for the [make.fun bounty "The joke the reviewer laughs at"](https://make.fun/bounty/the-joke-the-reviewer-laughs-at-20261121-0329).

`main.py` (Python 3.13, standard library only, no network) writes one one-line joke
about working beside an AI coding agent to `/output/entry.txt`.

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```
